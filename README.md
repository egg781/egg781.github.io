# 数据结构研习社

考研数据结构刷题平台 —— 纯静态 PWA，无需后端，数据存在浏览器本地。

## 功能

- **123 道题库**：选择题 84 / 综合应用题 39，覆盖 2009–2026 统考真题 + 期中期末 + 王道教材精选
- **72 张知识点卡片**：8 章核心考点 + C 语言基础 + 算法题答题模板 + 应用题策略 + 王道教材考点精编
- **题库搜索与筛选**：关键词全文检索（题干/选项/解析），六维筛选（章节 / 题型 / 难度 / 来源 / 做题状态），命中高亮与片段预览，可一键「刷这 N 题」
- **刷题模式**：分级课程、真题闯关、错题本、收藏、按章节练习、薄弱点推荐
- **学习数据**：做题记录、正确率、章节统计、每日目标、数据导入导出

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单页应用（含全部 CSS 与路由） |
| `data-ds.js` | LEVELS / CHAPTERS / KNOWLEDGE（72 张卡片） |
| `data-ds-q.js` | QUESTION_BANK（123 道题） |
| `search.js` | 搜索与筛选模块 |
| `manifest.json` | PWA 清单 |
| `sw.js` | Service Worker（离线缓存） |

## 本地运行

因为是纯静态站点，直接用浏览器打开 `index.html` 即可。若需本地服务器：

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080

## 部署

通过 GitHub Pages 自动发布，推送到 `main` 分支即更新。

## 数据存储

学习记录保存在浏览器 `localStorage`（键：`DS_USERS` / `DS_SESSION` / `DS_DATA_<用户名>`）。
换设备可用「我的 → 导出学习数据」备份，再在新设备导入。
